Context Workspace
Included by default

Sent to the model before your first message, so it knows the project without being told.

  • Instruction documents AGENTS.md, README.md, and .github/copilot-instructions.md, each as a short excerpt.
  • Project shape Folder name, git branch and remote, language breakdown, and a small directory tree.
  • Editor state Follows the file you are looking at: its path, language, and the open editors. Turn this off below.
  • Current selection The text you have highlighted, quoted verbatim. Separate control below.
  • Changed files A notice of files changed since the last turn, so the model knows what moved.
Editor state

When off, the composer strip shows no current file and sends no editor state.

Selection

Selected text is sent verbatim, including anything sensitive inside it.

Size limit
KB Resolved default 20 KB

Applies to the whole context block. When the cap bites, categories are trimmed in order: open editors, instruction documents, then the tree. Resolved default is 20 KB.

Ignore patterns

Pre-filled with the documented defaults. Patterns here are additive to the built-in secret and key set, which is always on and cannot be removed. An excluded path is never read.

  • node_modules/ Built-in
  • dist/ Built-in
  • *.min.js Built-in
  • package-lock.json Built-in
  • .env Built-in
  • **/*.generated.ts
  • fixtures/**

Also honors Files: Exclude and Search: Exclude.

Saved to melink.context.exclude, which the snapshot service reads.

Scope

These are workspace defaults. The composer can narrow them for a single turn; it never widens them unless you change a setting here.

Unsaved changes apply to the next turn.
